# Daily Report — 2026-09-11

## Summary

Accept S1_SMI calibration coefficients from caller instead of hardcoding.

## Changes

**`c670941` fix: accept S1_SMI calibration coefficients from caller instead of hardcoding**

- **`services/ndvi/src/models.rs`**: Added `alpha`, `beta`, `gamma`, `orbit_state` optional fields to `ComputeRequest`.
- **`services/ndvi/src/pipeline.rs`**: `run_pipeline()` and `compute_index()` now accept `alpha/beta/gamma` as parameters. Removed hardcoded 0.70/-0.30/0.50 coefficients. S1_SMI formula: `alpha * VV_dB + beta * VH_dB + gamma`.
- **`services/ndvi/src/routes.rs`**: `compute()` and `preprocess()` handlers extract coefficients from request payload, defaults to 0.70/-0.30/0.50 for backward compatibility.

## Impact

Django now forwards profile-specific calibration coefficients (e.g., `east_africa` from `s1_smi_calibration.yaml`) to Rust. Backward compatible — defaults match previous hardcoded values.
